Part 2 — Opening a Folder

Always open a folder in VS Code, not individual files. This sets the working directory for the terminal.

  1. Go to File > Open Folder

  2. Navigate to your target folder (e.g. Documents\sdgai\c1339c)

  3. Click Select Folder

The Explorer panel on the left will now show all files inside that folder.

Part 3 — The Integrated Terminal

The terminal lets you run commands without leaving VS Code.

Tip: Always open a new terminal after changing your Python environment so the correct environment is loaded.

Part 5 — Creating and Running a Jupyter Notebook

Create a new notebook

  1. Go to File > Open Folder and open your c1339c folder

  2. In the Explorer panel, click the New File icon

  3. Name the file with a .ipynb extension (e.g. my_notebook.ipynb)

  4. VS Code opens it as a Jupyter Notebook

Select the kernel (Python environment)

  1. Click the Select Kernel button in the top-right of the notebook

  2. Choose Python Environments

  3. Select ai-course (the environment created during setup)

If ai-course does not appear, return to the Python Environment Setup activity and verify the installation.

Keyboard shortcuts inside a notebook

Command mode vs edit mode: Press Esc to enter command mode (the cell border turns blue). Press Enter to start editing a cell.

Part 6 — Saving Your Work

  • Save the active file with Ctrl+S (Windows) or Cmd+S (Mac)

  • VS Code auto-saves by default — check File > Auto Save is ticked

  • Notebook cell outputs are saved with the file — you do not need to re-run cells each time you open the file
