Introduction to APIs¶

An API (Application Programming Interface) is a mechanism that allows different software applications to communicate with each other. APIs allow applications to request or provide data and services to other systems, and they are found in virtually every modern software application.

What is an API Call?¶

An API call is a request sent by a software application to an API, followed by a response from the server. This request–response cycle is the cornerstone of networked API communication, enabling retrieval, creation, modification, and deletion of data.

Core Concepts¶

Concept Description
Endpoint The URL where requests are sent. Example: https://api.example.com/getWeather
HTTP Methods GET (retrieve data), POST (send data), PUT (update data), DELETE (remove data)
Headers Additional information sent with the request (e.g., authorisation tokens, content type)
Parameters Data included with the request to filter results. Example: ?city=Singapore
Request Body Data sent to the server — used with POST and PUT requests
Response Data returned from the server: a status code, headers, and a body (often JSON)
Authentication Verifies permission to access the API — typically via API keys or OAuth tokens
Rate Limiting Restrictions on the number of requests per time period to prevent abuse
Error Handling Identifying and responding to errors during the API call process

HTTP Status Codes¶

Code Meaning
200 OK Successful request
201 Created Resource created successfully
204 No Content Successful, but no content returned
400 Bad Request Missing or invalid parameters
401 Unauthorized Authentication failed
403 Forbidden Authenticated but no access to this resource
404 Not Found Resource does not exist
500 Internal Server Error Server-side error
503 Service Unavailable Server not ready (maintenance or overload)

The Singapore Government's Open Data API (data.gov.sg) provides real-time data across many domains including environment, transport, and housing. The environment endpoints include air temperature, rainfall, humidity, and weather forecasts.

The Singapore Government’s Weather API v2 provides real-time weather data for Singapore. It is part of the Real-Time APIs suite on data.gov.sg, which also includes Collection and Dataset APIs. This API allows developers to query current weather conditions, offering a crucial resource for applications needing up-to-date weather information. Data is structured in collections and datasets, providing an efficient way to access various governmental data.

24def print_data_summary(temperature_data, precipitation_data):
25    """
26    Print a summary of stations with both temperature and precipitation data.
27
28    Parameters:
29    temperature_data (dict): The temperature data retrieved from the API.
30    precipitation_data (dict): The precipitation data retrieved from the API.
31
32    The function extracts station information, matches temperature and precipitation readings,

46        station_id = temp_reading['stationId']
47        if station_id in stations:
48            stations[station_id]['temperature'] = f"{temp_reading['value']}°C"
49    
50    # Process precipitation stations (there may be new stations not in temperature data)
51    for station in precipitation_data['data']['stations']:
52        station_id = station['id']
53        if station_id not in stations:
54            stations[station_id] = {'name': station['name'], 'temperature': None, 'precipitation': None}
55    
56    # Update the dictionary with precipitation readings
57    precip_items = precipitation_data.get('data', {}).get('readings', [])
58    for precip_reading in precip_items[0].get('data', []):
59        station_id = precip_reading['stationId']
60        if station_id in stations:
61            stations[station_id]['precipitation'] = f"{precip_reading['value']}mm"
62    
63    # Sort stations alphabetically by name
64    sorted_stations = sorted(stations.values(), key=lambda x: x['name'])
65    
66    # Print only stations with both temperature and precipitation readings
67    for station in sorted_stations:
68        if station['temperature'] is not None and station['precipitation'] is not None:

Matplotlib and Seaborn¶

Matplotlib vs. Seaborn: A Comparison of Python Visualization Libraries¶

Matplotlib and Seaborn are two widely-used libraries for data visualization in Python, each serving distinct purposes.

  • Matplotlib is a low-level library, offering extensive flexibility and control over every aspect of a plot's appearance, making it ideal for highly customized visualizations.

  • Seaborn, built on top of Matplotlib, simplifies complex visualizations with a high-level interface and provides a range of predefined, aesthetically appealing plot types. It is especially suited for statistical graphics and quick exploratory data analysis.

Both libraries complement each other, allowing users to leverage Seaborn’s simplicity while accessing Matplotlib's customization capabilities when needed.

When to Use Which Chart¶

Chart Type Best Used When
Bar chart Comparing values across categories
Line graph Showing change or trends over time
Pie chart Showing proportions of a whole (use sparingly — bar charts are often clearer)
Scatter plot Exploring the relationship between two numeric variables
Histogram Showing the distribution (spread) of a single numeric variable

 1import requests
 2import pandas as pd
 3from datetime import datetime, timezone
 4
 5def get_bitcoin_price():
 6    url = "https://api.coingecko.com/api/v3/simple/price"
 7    params = {
 8        'ids': 'bitcoin',
 9        'vs_currencies': 'USD',
10        'include_market_cap': 'true',
11        'include_24hr_vol': 'true',
12        'include_24hr_change': 'true',
13        'include_last_updated_at': 'true',
14        'precision': 'full'
15    }
16    response = requests.get(url, params=params)
17    data = response.json()
18    return data
19
20def format_data(data):
21    bitcoin_info = {
22        'Price (USD)': f"${data['bitcoin']['usd']:.2f}",
23        'Market Cap (USD)': f"${data['bitcoin']['usd_market_cap']:.2f}",
24        '24hr Volume (USD)': f"${data['bitcoin']['usd_24h_vol']:.2f}",
25        '24hr Change (%)': f"{data['bitcoin']['usd_24h_change']:.2f}%",
26        'Last Updated': datetime.fromtimestamp(data['bitcoin']['last_updated_at'], timezone.utc).strftime('%d-%b-%Y %H:%M')
27    }
28    df = pd.DataFrame([bitcoin_info])
29    return df
